《自新 Reform》導演工作台 v31.4 互動房間平面圖＋音檔播放＋手機測試頁面 這是一個導演／排練／工作會議用的空間與流程工作台。 不是最終給觀眾使用的演出系統。 目前版本重點 - 所有章節／Action 都可以自由查看，不受流程條件限制。 - 條件只作為資訊顯示，不會鎖住前後瀏覽。 - 「目前節」「完成」「播放」都是工作／模擬標記，不會限制查看。 - 中央視覺可切換：照片／平面圖／360。 - 360 可放大成接近全螢幕檢視。 - 平面圖可依 Action 自動 highlight 對應房間／區域。 - 平面圖可進入「編輯房間」模式，直接點選新的房間定位。 - 右側「目前道具／物件」可獨立上下捲動。 - 道具的劇本原參考圖優先顯示。 - 音檔可直接在網頁內播放。 - 新增「測試頁面」：手機版介面以劇本與音檔為主，平面圖與目前道具可展開查看。 - 可直接用網址後加 #test 進入測試頁面。 -------------------------------------------------- 一、檔案結構 -------------------------------------------------- 建議資料夾： index.html project.json README.txt assets/ renai_1f_interactive.svg renai_2f_interactive.svg 音檔請直接放在與 index.html 相同的資料夾，例如： 1.phone ring.mp3 2.主角來電.mp3 3.外役與令安.mp3 4.外役與孝文.mp3 5.錄音機播放.mp3 6.軍官們講話.mp3 7.孝文內心戲.mp3 8.麗雪探監.mp3 9.令安跟小子朗.mp3 10.醫生與孝文.mp3 11.醫生：你們真的有把他送到醫院嗎？.mp3 12.圖書室.mp3 13.牢房內運動.mp3 14.牢房內運動-獄友(2).mp3 15.子朗電話2.mp3 SFX-notification.mp3 不要另外改音檔路徑。 目前 index.html 會用「同資料夾相對路徑」讀取這些檔案。 若播放器顯示找不到音檔： 1. 確認音檔與 index.html 在同一層。 2. 確認檔名完全一致，包含空格、中文、括號與副檔名。 3. 不要只改檔名但沒有同步更新 index.html。 -------------------------------------------------- 二、導演工作台 -------------------------------------------------- 左側 - 章節列表 - Action／節列表 - 所有節都可以自由點擊查看 中央 - 照片 - 平面圖 - 360 中央不再顯示舊版「自由查看模式＋下一節條件」大卡片， 因此照片／平面圖／360 可以使用更多垂直空間。 底部 - 上一節 - 下一節 - 設為目前節 - 完整劇本 - 音檔播放 - 技術／節資料 「下一節 →」仍保留下一節名稱與進入條件的提示資訊。 -------------------------------------------------- 三、360 -------------------------------------------------- 360 模式支援： - 設定此 Action 位置 - 另開官方 360 - ⛶ 放大 - ↙ 縮回 - Esc 縮回 - 點擊暗色背景縮回 - 切換到照片／平面圖時自動縮回 放大時沿用同一個 iframe， 不會因為放大／縮回而主動重建 360。 目前使用的 360 預設位置主要存放於： project.json → action360Scenes 之後新修改的 360 位置會先進： project.json → actionSettings → sceneOverride -------------------------------------------------- 四、互動平面圖 -------------------------------------------------- 平面圖模式提供： - 1F / 2F 切換 - Action 對應房間／區域 highlight - 編輯房間 - 清除定位 - 恢復預設 - 查看官方底圖 編輯方式： 一般點擊 ＝改成單一房間 Shift / Command / Ctrl + 點擊 ＝多選房間／區域 目前正式的預設房間資料存放於： project.json → actionRoomAssignments 之後新修改的房間定位會先進： project.json → actionSettings → roomAssignment 「恢復預設」會回到 actionRoomAssignments 中目前設定的值。 注意： 2F 目前只做到可確認的區域層級。 公開資料不足以可靠把劇本中的四個牢房對應成四個精確房號， 因此不會在系統裡假造房號。 -------------------------------------------------- 五、道具／物件 -------------------------------------------------- 右側「目前道具／物件」： - 可獨立上下捲動 - 標題與新增／已刪除／編輯工具維持在上方 - 劇本原參考圖優先作為主圖 - 其他後加參考圖片保留為次要圖片 - 道具說明可完整往下查看 「道具總覽」： - 一個實體道具只列一次 - 同一個實體道具可以關聯多個 Action - 可搜尋／篩選／編輯／刪除／恢復 - 父親的信已用 physical prop identity 合併跨場次關聯 相關資料主要在： project.json → propOverrides → customProps → hiddenProps → propIdentityLinks -------------------------------------------------- 六、音檔播放 -------------------------------------------------- 音檔播放器顯示在底部「劇本／流程工作區」， 位於完整劇本上方。 功能： - 播放／暫停 - 拖曳進度 - 音量控制 - 顯示實際檔名 - 顯示主劇情／提示音／現場音檔類型 - 播放新音檔時，自動暫停其他音檔，避免多軌意外疊加 目前已有明確檔名的音檔可以直接播放。 目前仍待提供的建置表音檔： - S15：餐桌家庭回憶 - S16：餐桌疊加讀書會 - S17：牢房一 - S18：牢房二 - S19：牢房三 - S20：牢房四 - S21：結尾語音訊息 這些 Action 目前會顯示「音檔待提供」， 不會產生壞掉的播放器。 -------------------------------------------------- 七、測試頁面 -------------------------------------------------- 導演工作台右上角有： 「測試頁面」 切換後會進入手機導向介面。 測試頁面主要顯示： 1. 音檔播放 2. 劇本 3. 觸發條件 4. 上一節／下一節 5. 平面圖（可展開） 6. 目前道具（可展開） 平面圖與目前道具在測試頁面都是唯讀， 真正修改仍回到導演工作台。 桌面上開啟時： - 會以約 480px 的手機寬度預覽 手機上開啟時： - 直接使用手機寬度 可直接用網址： 你的網址/#test 進入測試頁面。 例如： https://example.github.io/reform/#test 按「回導演工作台」即可切回正常工作台。 -------------------------------------------------- 八、project.json 與 index.html 的分工 -------------------------------------------------- index.html 負責： - UI - 顯示 - 互動 - 編輯器邏輯 - 音檔檔名 mapping - 測試頁面 - 內建 fallback project.json 負責： - 劇本資料 - Action 資料 - 360 預設位置 - 房間預設位置 - 編輯後的 override - 空間筆記 - 圖片 override - 道具資料 - physical prop identity 重要原則： 專案目前的正式預設值應優先放在 project.json。 index.html 裡的房間 fallback 只是在 project.json 沒資料時備援使用。 -------------------------------------------------- 九、儲存 -------------------------------------------------- 工作台內的「儲存」會把目前可保存的修改寫回 project.json。 如果直接從 GitHub 網頁上傳大型音檔遇到： “The file is too large and cannot be uploaded.” 建議不要把 WAV 大檔直接用網頁上傳。 目前網頁主要使用 MP3。 若需要把較大的 MP3 放進 repository， 建議使用 GitHub Desktop 或本機 Git push。 注意： GitHub Pages 不適合把播放用音檔改成 Git LFS 資源， 因為網頁需要能直接讀取音檔 URL。 -------------------------------------------------- 十、目前版本 -------------------------------------------------- HTML： v31.4 資料基準： v31.2 之後的 project.json 主要版本演進： v29 -
