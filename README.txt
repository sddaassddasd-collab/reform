《自新 Reform》導演工作台 v30.3 — 道具總覽清單版

這版針對 v30.2 截圖中「卡片互相疊壓、只剩標題列」的問題，放棄卡片 Grid，改成穩定的 inventory 清單。

只修改「道具總覽」，主工作台不動。

新總覽
- 一件實體道具 = 一整列。
- 左側：固定大小縮圖。
- 中間：道具名稱、類型、兩行說明摘要、章節／圖片標記。
- 右側：前 2 個關聯節、「查看全部 N 個關聯節」、編輯。
- 每列完全獨立，只往下排列，不會因另一件道具內容較長而拉高、重疊或壓縮。
- 22 件、30 件或更多道具只會增加垂直捲動。

響應式
- 桌機：縮圖 / 資訊 / 關聯節三欄。
- 中型畫面：縮圖 + 資訊，關聯節移到下一列。
- 手機：更小縮圖，關聯節單欄排列。
- 不會為了維持多欄而縮小文字或點擊區。

保留
- 同一實體道具跨場景 identity。
- 搜尋、章節、類型、圖片篩選。
- Google Drive / 原參考圖預覽。
- 從道具跳到節。
- 查看全部關聯節浮層。
- 編輯道具。
