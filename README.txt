《自新 Reform》導演工作台 v30.1 — 道具總覽易讀版

本版只調整「道具總覽」，主工作台與右側目前道具區沒有改動。

修正內容
- 桌機總覽由 3 欄改為 2 欄，避免卡片被擠窄。
- 中型與小型螢幕改成 1 欄。
- 卡片改成橫向配置：左側圖片、右側資訊。
- 道具名稱、類型、說明、badge、關聯節、編輯按鈕全面放大。
- 關聯節按鈕改成整列、大點擊區，完整顯示節名稱，不再只有小膠囊。
- 每件道具預設只顯示前 3 個關聯節；更多時顯示「顯示全部 N 個關聯節」。
- 道具很多時只增加總覽內部捲動，不會壓縮卡片或字體。
- 原本的實體道具 identity、跨場景關聯、搜尋、篩選、編輯與跳轉邏輯全部保留。
