《自新 Reform》導演工作台 v30.2 — 道具總覽穩定版

本版只修「道具總覽」以及它本身的 HTML 結構，不改主工作台。

修正重點
1. 修正 v30.1 的 HTML 結構
   - 原本主工作台後先出現一個 </body>，道具總覽與後續 overlay 實際落在 body 外。
   - v30.2 移除提早關閉的 body，整份文件只保留一組合法的 <body>...</body>。

2. 卡片不再互相拉高
   - 總覽 Grid 加入 align-items:start。
   - 每張卡高度由自己的內容決定。
   - 圖片固定在獨立 150×150 顯示框，不會因隔壁卡片文字多而被拉長。

3. 卡片不再被硬擠成小尺寸
   - 桌機採 auto-fit + 最低約 460px 卡片寬度。
   - 空間不足時直接變成單欄，不維持兩張超窄卡片。

4. 長說明不再把卡片撐爆
   - 總覽中的說明最多顯示 4 行摘要。
   - 完整內容仍保留，可從編輯器查看；滑鼠停留也可看到完整文字。

5. 關聯節不再在卡片內無限展開
   - 卡片最多直接顯示前 3 個關聯節。
   - 超過 3 個時顯示「查看全部 N 個關聯節」。
   - 點擊後開獨立浮層列出全部關聯節，不會改變卡片高度。
   - 點浮層中的節會回到流程頁查看該節，不改目前模擬節或完成標記。

6. 原有功能保留
   - 同一實體道具跨場景 identity
   - 搜尋與篩選
   - 道具編輯
   - Google Drive 參考圖片
   - 從道具跳回場景
