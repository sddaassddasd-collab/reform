《自新 Reform》導演工作台 v29 — 自由查看版

定位
這個版本把工具明確改成「開會／排練／導演查看工作台」，不是正式演出流程控制器。

核心變更
- 所有章、所有節永遠可以直接點擊查看。
- 上一節／下一節永遠只負責查看前後節，不檢查前置條件。
- 條件仍完整保留並顯示，但只作資訊提示。
- 4-05 後可直接查看 5-01；5-01 仍顯示「約半小時後」的劇本條件。
- Chapter 6、Chapter 7 可任意跳動，不會被 completed、cursor 或 prerequisite 擋住。
- 「設為目前節」只用來在會議／排練中標記現在正在討論或模擬的位置。
- 切換目前節不會自動把上一節算完成。
- 「標記此節完成」只是工作標記，不影響能否跳到任何其他節。
- 原本的 completed / history 仍保留作為工作記號，但不再作為導航權限。
- 「查看本章第一節」不會清空後面的狀態。
- 「查看 5-01（劇本：約半小時後）」只是查看快捷鍵，不重置任何資料。
- 「清除模擬標記」只清 current / completed / history，不改劇本、筆記、圖片、道具或 360。

介面
- 底部主要控制：← 上一節 / 下一節 →
- 第三顆較弱的控制：設為目前節；若此節正在模擬則變成「標記此節完成」。
- 中央「下一節」卡會顯示下一節名稱、進入條件，以及目前工作標記是否符合；即使不符合仍可直接查看。

資料
- project.json 結構不需要為這次自由導航新增欄位。
- 既有劇本、筆記、道具、圖片、Google Drive 參考圖、360、GitHub 儲存功能全部保留。
