《自新 Reform》導演工作台 v30 — 道具總覽與跨場景版

這版新增「實體道具」概念。

一、道具總覽
- 頂端新增「道具總覽」。
- 所有道具集中在同一頁。
- 可搜尋道具名稱、說明、Action。
- 可依章節、類型、圖片狀態篩選。
- 每張卡直接列出所有關聯節。
- 點某個節只會切換查看位置，不會改「目前節」或完成標記。
- 可從總覽直接開啟該實體道具的編輯器。

二、同一件道具跨場景
- 同一件實體道具只在總覽列一次。
- 同一件道具可以關聯不同章節的 Action。
- 編輯器的 Action 清單改為全劇 29 個 Action，依章節分組。
- 名稱、類型、說明、圖片等都是「實體道具」層級資料；從任何關聯場景編輯都會改到同一筆。
- 刪除跨場景道具時，會從所有關聯場景一起隱藏，仍可從「已刪除」恢復。

三、既有資料合併
目前劇本中明確為同一件實體物件的：
- 第一章「父親寫給母親的信＋夾帶紙條」
- 第八章「父親的信（再次被提起）」

已合併為同一個 physical prop：
physical::father-letter

總覽只會顯示一筆，關聯：
- 1-02
- 1-03
- 8-01

四、新增道具
- 新增道具仍可指定一個主要章節做資料歸檔。
- 但 Action 關聯現在可跨章勾選。
- 因此同一件新道具若跨多個場景，不需要再新增第二筆。

五、相容性
- 原本的 propOverrides / imageOverrides / customProps / hiddenProps 繼續保留。
- 新增 propIdentityLinks，讓多個舊場景紀錄可指向同一件實體道具。
- 既有劇本、筆記、Google Drive 圖片、360、GitHub「儲存」功能全部保留。

補充修正
- 「新增道具」的主要章節只是歸檔位置；切換主要章節不會清掉已勾選的跨章 Action。
- propIdentityLinks 在 GitHub 儲存成功後會同步提升為目前正式資料，跨場景 identity 不會掉回舊狀態。
